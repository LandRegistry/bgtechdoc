Global

Bad Request

Type: bad_request

Detail: The request is invalid or malformed

Resolution:

  • Double check the syntax of the request.
  • Ensure all fields/parameters/headers in the request are the correct type, format and location.
  • Ensure all required fields/parameters/headers are included in the request.

Example:


{
    "type": "https://landregistry.github.io/bgtechdoc/problems/bad_request",
    "title": "Bad Request",
    "detail": "The request is invalid or malformed",
    "status": 400,
    "errors": {
        "detail": "The name 'F' is too short and must be at least 10 characters.",
        "pointer": "$.data.name"
    }
}

Unauthorized

Type: unauthorized

Detail: The request could not be authorized

Resolution:

  • Ensure an Authorization header is included in the request.
  • Verify a valid username and password pair has been converted to base64.
  • Verify credentials are valid.

Example:


{
    "type": "https://landregistry.github.io/bgtechdoc/problems/unauthorized",
    "title": "Unauthorized",
    "detail": "The request could not be authorized",
    "status": 401,
    "errors": {
        "detail": "The name 'F' is too short and must be at least 10 characters.",
        "pointer": "$.data.name"
    }
}

Forbidden

Type: forbidden

Detail: The request could not be authorized

Resolution:

Not Found

Detail: The resource requested does not exist

    "status": 404

Internal Server Error

Type: server-error

Detail: An unexpected problem has occurred.

Resolution:

  • Please wait and try again at a later time.
  • If this issue persists please contact support.

Example:


{
    "type": "https://landregistry.github.io/bgtechdoc/problems/server-error",
    "title": "Internal Server Error",
    "detail": "An unexpected problem has occurred.",
    "status": 500
}
