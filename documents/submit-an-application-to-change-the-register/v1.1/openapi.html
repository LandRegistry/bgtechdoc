Notifications API

get_notifications_v1

Receive notifications API - Get any unacknowledged notifications

Authorizations:
basic_auth
query Parameters
status
string
Enum: "NEW" "ACKNOWLEDGED"

Status of the notifications - Either NEW or ACKNOWLEDGED. Default is NEW

additional_provider_filter
string or null [ 1 .. 50 ] characters

The Additional Provider filter used by the Provider

subject
string [ 0 .. 128 ] characters ^[A-Za-z0-9._@ -]*$

The Subject of the notification - this is currently the application_request_id

subject_type
string [ 0 .. 64 ] characters ^[A-Za-z0-9._@ -]*$
Default: ""

The type of Subject for the notification - currently only APPLICATION is available

notification_type
string [ 0 .. 255 ] characters ^[A-Za-z0-9._@ -]*$

The type of notification to search for

created_after
string <date-time>

Search for notifications with a created_timestamp after this date and time

created_before
string <date-time>

Search for notifications with a created_timestamp before this date and time

occurred_after
string <date-time>

Search for notifications with an event_timestamp after this date and time

occurred_before
string <date-time>

Search for notifications with an event_timestamp before this date and time

limit
integer <int32>

The maximum number of notifications to return in a single response

Responses

Production

https://businessgateway.landregistry.gov.uk/bg2/api/v1/notifications
