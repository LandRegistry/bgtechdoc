Scenario 2. Remortgage vendor test data

Note: Fee values used in this document are for example and are subject to change.

Scenario 2. remortgage

William Prynne and Tracey Prynne remortgage their home. The new mortage is for £206,000. The house is registered at HM Land Registry under title number ST500678. Tracey and William applied directly to their lender (Furness Building Society) for their mortgage and are not represented. The lender is represented by a conveyancer who submits the application to HM Land Registry. Tracey and William came into the new lender’s branch to confirm their identity with passports. The conveyancer ensures funds from the new mortgage is used to pay off the existing mortgage.

Documents required by HM Land Registry:

  • AP1 (Alteration of register)
  • Charge

HM Land Registry require the representation details for the borrowers and registering lender. Land Registry do not require representation details for the discharging lender as DS1 (Evidence of Discharge) is not submitted with the application.

Scenario 2A

At the time the application is submitted the existing lender (Abbey National PLC) has automatically completed an electronic DS1. The new charge will be added normally.

Scenario 2B

  • At the time the application is submitted, if the conveyancer representing Furness Building Society is uncertain if the discharging lender has sent the DS1 to HM Land Registry. So it still make applications for both the discharge and charge. HMLR will requisition for evidence of discharge if it has not already been submitted via DS1 or alternatively it can be completed via early completion.

Once the application has been processed a poll request for the completed application can be made. For the test stubs this has already been processed and so the poll can be completed at anytime. For the live service it will be expected that the outstanding request service will be used to validate the response. Confirming that the response has been generated, and is ready for collection.

Scenario 2 has two outcomes

  • polling for the response 2a will simulate the old lenders (Abbey National) having sent in an automated discharge for their charge
  • polling for the response 2b will simulate the old lenders not yet having sent the discharge in. The title will end up still holding this old charge along with the new charge (Furness Building Society)
