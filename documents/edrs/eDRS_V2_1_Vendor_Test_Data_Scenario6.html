Scenario 6. Dispositionary first lease (DFL) vendor test data

Scenario 6. Dispositionary first lease

Thomas and Jennifer Horsman own 15 Coral Close, Tuffley. They decide to lease the first floor flat to Roger Mellor for a period of 99 years for £90,000. The property is registered with HM Land Registry under title number GR521889. Roger’s conveyancer submits the application to HM Land Registry. The conveyancer acting for Thomas and Jennifer certifies their identity and requires third part notification once the application has been completed.

Documents required by HM Land Registry:

  • AP1 (Alteration of register)
  • lease
  • SDLT (Stamp Duty Land Tax)
  • DS3 (discharge)

HM Land Registry require the representation details for the lessor and lessee.

6.3 Attachment service

For this scenario the attachment service can be called once for each of the declared applications or supporting documents. Once for the lease, another for the discharge and the final SDLT form. The attachment Id should change to match the corresponding application or document.

Once the application has been processed a poll request for the completed application can be made. For the test stubs this has already been processed and so the poll can be completed at any time. For the live service it will be expected that the outstanding request service will be used to validate the response. This confirms that the response has been generated and is ready for collection.
