Request Official Copy with Documents Vendor Test Data V1.2

Note: The OC1 and OC2 share the same schema.

Choice of submission is indicated by the selection of the official copy type code (10 = OC1 and 20 = OC2).

All tests require the basic minimum data items (as per the schemas). This will actually be ignored by the test stub system but is needed to pass XML validation.

Items highlighted in red in the test documentation are needed for the test to return the correct response.
