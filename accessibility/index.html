Accessibility Statement

Business Gateway technical documentation

This accessibility statement applies to the Business Gateway developer pack documentation and guides.

This website is run by HM Land Registry. We want as many people as possible to be able to use this website. For example, that means you should be able to:

  • change colours, contrast levels and fonts using browser or device settings
  • zoom in up to 400% without the text spilling off the screen
  • navigate most of the website using just a keyboard
  • navigate most of the website using speech recognition software
  • listen to most of the website using a screen reader (including the most recent versions of JAWS, NVDA, and Voiceover)

We’re also aiming to make the website text as simple as possible to understand.

Get advice from AbilityNet on making your device easier to use if you have a disability.

How accessible this website is

We know some parts of this website are not fully accessible:

  • a number of pages have arrows to indicate expanding a table
  • some code segments are not focusable
  • a page has the word below to refer to tables
  • a page has partially incorrect heading styles
  • some lists in tables are not formatted correctly on a page
  • there are issues caused by our technical documentation template
  • our OpenAPI pages are controlled by a third-party-owned component which is inaccessible

Feedback and contact information

  • If you find any problems not listed on this page or think we’re not meeting accessibility requirements, contact our customer support centre.

You can also contact us if you need information on this website in a different format like:

  • accessible PDF
  • large print
  • easy read
  • audio recording
  • braille

Enforcement procedure

The Equality and Human Rights Comission (EHRC) is responsible for envforcing the Public Sector Bodies (Websites and Mobile Applications) (No. 2) Accessibility Regulations 2018 (the ‘accessibility regulations’). If you’re not happy with how we respond to your complaint, contact the Equality Advisory and Support Service (EASS).

Technical information about this website’s accessibility

HM Land Registry is committed to making its website accessible, in accordance with the Public Sector Bodies (Website and Mobile Applications)(No. 2) Accessibility Regulations 2018.

Compliance status

This website is partially compliant with the Web Content Accessibility Guidelines (WCAG) 2.2 AA standard, due to the non-compliances listed below.

Non-accessible content

The content listed below is non-accessible for the following reasons.

Non-compliance with the accessibility regulations

  1. Some headings on the ‘A guide for developers’ page do not have the correct labels. This means assistive technologies will not read the content correctly. This fails WCAG 2.2 AA Success Criterion 2.4.6 (Headings and Labels).
  2. Some labels for the search box input are missing. This fails WCAG 2.2 A Success Criterion 1.3.1 (Info and Relationships) and WCAG 2.2 A Success Criterion 2.5.3 (Label in Name).
  3. Some labels coded within the page will be shown missing. This fails WCAG 2.2 A Success Criterion 3.3.2 (Labels or Instructions).

Content that’s not within the scope of the accessibility regulations

PDFs and other documents

The accessibility regulations do not require us to fix PDFs or other documents published before 23 September 2018 if they’re not essential to providing our services.

What we’re doing to improve accessibility

We are planning on reviewing and fixing the WCAG 2.2 non-compliances soon.

We are in the process of replacing the PDF guides on this website with accessible HTML documents.

How we tested this website

This website was tested against the WCAG 2.2 AA standard. The Business Gateway team tested every page of our Business Gateway technical documentation manually.

This statement was prepared on 21, December 2023. It was last reviewed on 31, October 2024.
